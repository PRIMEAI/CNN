Laboratoire de filtres sur une image

Moulay Akhloufi

Avant l’apprentissage profond, on concevait les filtres à la main : Sobel pour les contours, Gabor pour les textures orientées. Chaque filtre transforme l’image en une carte de caractéristiques. Un CNN apprend lui-même des filtres de ce type dans ses premières couches.

Banc de filtres de Gabor : 4 orientations → 4 cartes

Avec plusieurs filtres, l’image devient un empilement de cartes, une par filtre : c’est l’« espace de caractéristiques » (diapo 23). Chaque carte s’allume là où l’image contient des structures de cette orientation. C’est exactement ce que produit une couche de convolution à K filtres.

À retenir

Sobel X = [−1 0 1; −2 0 2; −1 0 1] répond aux variations horizontales d’intensité, donc aux contours verticaux. Sobel Y fait l’inverse. La magnitude √(Gx² + Gy²) donne tous les contours.
Le filtre de Gabor est une sinusoïde (longueur d’onde λ, orientation θ, phase ψ) multipliée par une gaussienne (largeur σ, allongement γ) : g(x, y) = exp(−(x′² + γ²y′²) / 2σ²) · cos(2π x′/λ + ψ), avec x′ = x cos θ + y sin θ. Les premières couches d’un CNN entraîné ressemblent beaucoup à des filtres de Gabor, comme les cellules simples du cortex visuel (Hubel et Wiesel).
